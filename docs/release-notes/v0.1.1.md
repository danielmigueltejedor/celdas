Celdas se pone al día con las otras apps de ofimática de Nodalia: arranca en Inicio y comparte la vista Archivo.
*Celdas catches up with Nodalia's other office apps: it starts on Home and shares their File view.*

## Español

### Novedades
- **Pantalla de inicio:** al abrir Celdas sin un archivo aparece Archivo › Inicio, con las plantillas y los libros recientes, como en Letra y Lámina. Se puede desactivar en Preferencias › General.
- **Vista Archivo común:** Inicio, Nuevo, Abrir y Preferencias usan la misma vista que el resto de las apps de ofimática de Nodalia.
- **Acerca de Celdas:** nueva ventana con el diseño de Nodalia, con el icono, la versión y los enlaces al sitio web y a la licencia.
- **Menú principal:** más espacio entre los iconos y el texto.

## English

### What's new
- **Start screen:** opening Celdas without a file shows File › Home, with the templates and recent workbooks, as Letra and Lámina do. Turn it off in Preferences › General.
- **Shared File view:** Home, New, Open and Preferences use the same view as Nodalia's other office apps.
- **About Celdas:** a new window in the Nodalia design, with the icon, the version, and links to the website and the licence.
- **Main menu:** more room between the icons and the labels.
